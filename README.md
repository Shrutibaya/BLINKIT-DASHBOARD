
# 🚀 Blinkit Sales Analysis Dashboard | Power BI

## 📌 Project Overview

Developed an interactive Power BI dashboard to analyze Blinkit's grocery sales performance, product distribution, and outlet-level business trends. This project transforms raw sales data into actionable business insights through KPI cards, interactive charts, and dynamic filters.

## 🎯 Key Objectives

- Analyze total sales, average sales, and overall item performance.
- Monitor customer satisfaction using average product ratings.
- Evaluate sales distribution across product categories and outlet characteristics.
- Enable interactive, self-service data exploration through slicers and filters.

## 📊 Dashboard Features

- **KPI Cards:** Total Sales, Average Sales, Number of Items, and Average Rating.
- **Donut Charts:** Visualize sales distribution by fat content, including Low Fat and Regular products.
- **Bar Charts:** Compare sales across item types, outlet sizes, and outlet locations.
- **Line Charts:** Analyze outlet establishment trends and sales performance over time.
- **Treemap Visualizations:** Compare outlet types based on sales and other performance metrics.
- **Interactive Filters:** Explore insights by item type, outlet location tier, outlet size, and establishment year.

## 🛠️ Tools & Technologies

- **Power BI:** Dashboard development, data modeling, and visualization.
- **Power Query (M):** Data cleaning, transformation, and formatting.
- **DAX:** Calculated measures and KPI development.
- **Microsoft Excel / CSV:** Data source and preliminary data handling.

## 🔍 Dataset

Used a publicly available Blinkit grocery sales dataset containing information about item types, sales values, fat content, customer ratings, outlet locations, outlet sizes, and outlet establishment years.

## 📈 Key Insights

- Low Fat and Regular product categories contribute to overall sales, with their relative performance explored through interactive visualizations.
- Outlet types demonstrate different sales and product visibility patterns.
- Outlet size and location tier help explain variations in sales performance.
- Average customer ratings are approximately 3.9 in the analyzed dataset, highlighting opportunities to improve customer satisfaction at underperforming outlets.

## 💡 Business Value

- Supports data-driven sales and inventory decisions.
- Helps identify high-performing product categories and outlet segments.
- Enables comparison of outlet performance across locations and sizes.
- Provides an interactive reporting experience for faster business analysis.

## ✅ Project Outcome

Successfully built an interactive sales analytics dashboard that converts raw grocery sales data into meaningful business insights using Power BI, Power Query, and DAX.
